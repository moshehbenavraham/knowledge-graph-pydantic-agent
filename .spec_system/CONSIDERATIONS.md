## Lessons Learned

Proven patterns and anti-patterns. Reference during implementation.

### What Worked
<!-- Max 15 items -->

- Dual-database architecture (PostgreSQL vectors + Neo4j graph)
- Intent-based query routing for search optimization
- Handler pattern for UI feature modularity
- Pydantic Settings for centralized configuration
- Structured logging with structlog for debugging
- Analytics batched writes for low overhead (<5ms)

### What to Avoid
<!-- Max 10 items -->

- Creating multiple agent implementations (violates unified agent principle)
- Using os.getenv() directly (use centralized config)
- Trailing semicolons in Supabase RPC SQL queries
- Using deprecated `run_mcp_servers()` (use `async with agent:`)
- Blocking operations in async contexts

### Tool/Library Notes
<!-- Max 5 items -->

- Pydantic AI: Tool calls visible during streaming but results appear only after completion
- Streamlit: Tool arguments incomplete during streaming (show pending state)
- pgvector: Vector dimension must match embedding model (1536 OpenAI, 768 Ollama)
