# Risk Register

| Area | Risk | Evidence | Impact | Mitigation |
| --- | --- | --- | --- | --- |
| Security | No authentication/authorization on API routes; rate limiting exists but not bound to user identity. | FastAPI main does not mount auth middleware and endpoints are public; rate limiting endpoints operate without credentials.【F:src/api/main.py†L105-L135】【F:src/api/health_endpoints.py†L80-L104】 | Exposure of ingestion/search/chat to unauthenticated users. | Introduce API key or OAuth middleware; enforce auth dependencies on routers. |
| Security | Credentials required for LLM/Supabase/Neo4j passed via environment with no secret rotation guidance. | Docker Compose exposes sensitive env vars (LLM_API_KEY, SUPABASE_SERVICE_KEY, NEO4J_PASSWORD).【F:docker-compose.yml†L10-L48】 | Key leakage risk when sharing Compose files/logs. | Integrate secrets manager (Vault, AWS SM) and document rotation cadence. |
| Security | Tooling dependency `interrogate` pulls `py==1.11.0` with disputed CVE (noted). | `pyproject.toml` comment acknowledges CVE-2022-42969 accepted risk.【F:pyproject.toml†L54-L77】 | Potential audit finding during supply-chain review. | Lock patched version or justify with formal risk acceptance in SBOM. |
| Reliability | FastAPI dependency bootstrap fails because Postgres/Neo4j stores instantiated without connection manager. | `init_dependencies` constructs stores without arguments, conflicting with constructors.【F:src/api/dependencies.py†L33-L138】【F:src/agentic_rag/storage/postgres_store.py†L16-L24】 | API cannot start, causing downtime. | Fix constructors and add startup tests. |
| Reliability | Document ingestion pipeline assumes synchronous initialization; missing call to `initialize()` will break Neo4j connection. | `DocumentIngestionPipeline` warns `await pipeline.initialize()` is required, but API ingestion endpoint bypasses (instantiates pipeline and calls `ingest_document` immediately).【F:src/agentic_rag/ingestion/pipeline.py†L83-L166】【F:src/api/endpoints/documents.py†L56-L90】 | Runtime errors when pipeline tries to use uninitialized connection manager. | Ensure endpoint awaits `initialize()` or reuses shared pipeline via dependency injection. |
| Data Governance | Postgres stores full document content and metadata but ingestion pipeline lacks PII scrubbing/consent checks. | `store_document` persists raw content and metadata; no redaction step.【F:src/agentic_rag/storage/postgres_store.py†L25-L48】 | Compliance risk for sensitive uploads. | Add PII detection scrub step and configurable retention policies. |
| Observability | OTEL instrumentation optional import, not activated unless manually toggled; Prometheus metrics limited to custom counters. | `FastAPIInstrumentor` optional; metrics created manually per endpoint.【F:src/api/main.py†L39-L110】【F:src/api/endpoints/search.py†L41-L110】 | Limited tracing/metrics in production. | Enforce tracing initialization via config and integrate request-level Prometheus exporter. |
| Scalability | Redis cache optional; if disabled, search/chat rely on in-process caches with no eviction persistence. | `VectorSearch` uses in-memory cache when `enable_caching` false; API cache requires external Redis but not mandatory.【F:src/agentic_rag/search/vector_search.py†L127-L200】【F:src/api/dependencies.py†L33-L131】 | Increased latency under load if caching misconfigured. | Make Redis mandatory in production profiles; add health checks. |
| Maintainability | Graph endpoints, reindex, stats marked TODO leading to dead paths and inconsistent data. | `documents` and `search` routers contain TODO placeholders.【F:src/api/endpoints/documents.py†L236-L395】【F:src/api/endpoints/search.py†L161-L223】 | Technical debt accumulates, making maintenance harder. | Track TODOs in backlog, implement or disable routes until complete. |
